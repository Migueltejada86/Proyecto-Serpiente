# Bill of Materials — Prototipo v0.1 (~30 cm)

Cantidades orientativas para 5–6 segmentos.

## Electrónica

| Item | Cantidad | Notas |
|------|----------|-------|
| ESP32 DevKit | 1 | Preferible con WiFi/BT |
| PCA9685 (16-ch PWM) | 1 | Imprescindible para múltiples servos |
| Servos MG90S (o SG90) | 6 | Metal gear recomendado si se consigue |
| ESP32-CAM (AI-Thinker) o cámara pequeña | 1 | Para vista frontal |
| Batería LiPo 2S (o pack 18650) + regulador 5V alta corriente | 1 | No alimentar servos desde el ESP32 |
| Cables Dupont, conectores | - | Para cableado ordenado |
| Interruptor / conector de alimentación | 1 | |

## Mecánica / Impresión 3D

| Item | Cantidad | Notas |
|------|----------|-------|
| Filamento PLA o PETG | ~100–150 g | Locales de Alta Gracia |
| Tornillos M2 / M2.5 (según diseño) | varios | Para fijar servos y unir segmentos |
| Tuercas o inserts (opcional) | varios | |

## Opcional / Mejoras futuras

- Sensor ToF (VL53L0X) o ultrasónico
- IMU
- Buzzer o LEDs en la cabeza
- Mejor sistema de batería con BMS
